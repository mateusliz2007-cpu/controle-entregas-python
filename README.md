

\# Sistema de Gestão de Entregas



Projeto desenvolvido em Python para praticar programação e automatizar cálculos relacionados à gestão de entregas.



\## Tecnologias utilizadas



\- Python

\- Git

\- GitHub



\## Como executar



1\. Instale o Python.

2\. Abra o terminal na pasta do projeto.

3\. Execute o comando:



```bash

python main.py

```



\## Objetivo



Aplicar conhecimentos de programação a problemas relacionados à logística e às operações de transporte.
